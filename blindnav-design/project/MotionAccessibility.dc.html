Speech priority: SOS, critical hazard, caution, your request, navigation, ambient. A lower one never cuts off a higher one.

Layout on Android

  • Design size 393 × 852 dp; fluid from 360 to 430 dp wide.
  • Text scales to 200% without clipping; screens scroll.
  • Portrait only; respect system insets; bottom bar clear of the gesture area.
  • Theme tokens map one to one to the Compose colour scheme.

Rules every screen must pass

  • Voice first: every task can be done by speaking.
  • Never colour alone: icon, word and border style too.
  • Spoken status: every state change is announced.
  • Touch: 56 dp minimum, 64 preferred; one action per row.
  • Focus order: title, primary action, content, secondary, Back last.
  • Contrast: 4.5:1 for text, 3:1 for icons and borders.
  • Honest: the AI is advisory. It never says a road is safe.
  • Cane first: “Assists only” is on screen and spoken.
  • Fails loudly: camera, GPS or AI failure is spoken at once.
